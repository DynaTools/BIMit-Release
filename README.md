# BIMit — WBS per Revit

BIMit assegna la **WBS** agli elementi del modello Revit: parti dalla WBS normativa o da una
tua struttura, definisci i parametri una volta per tutto il progetto, cambia solo quello che serve
in ogni categoria, controlla l'anteprima e scrivi nel modello.

Durante la **beta** BIMit è gratuito.

## Requisiti

- Windows 10 o 11
- Autodesk Revit 2023, 2024, 2025 o 2026
- Un account DynaTools (lo stesso di UniBIM), che crei dal plugin al primo avvio

## Installazione

1. Chiudi Revit.
2. Scarica `BIMit_Setup_<versione>.msi` dall'ultima [release](../../releases/latest).
3. Aprilo con doppio clic. **Non servono permessi di amministratore**: BIMit si installa solo per
   il tuo utente, per tutte le versioni di Revit presenti.
4. Apri Revit: trovi la scheda **BIMit**.

Se Windows mostra l'avviso SmartScreen, scegli *Ulteriori informazioni* → *Esegui comunque*.

## Aggiornamenti

BIMit controlla da solo se c'è una nuova versione e te la propone: la scarica, ne verifica
l'integrità e la installa quando chiudi Revit. Alcuni aggiornamenti possono essere necessari per
continuare a usare il plugin.

## Disinstallazione

*Impostazioni di Windows* → *App* → *App installate* → **BIMit** → *Disinstalla*.
Per eliminare anche il tuo account e i dati: in Revit, *BIMit* → *Account* → *Elimina account*.
